# 321学习法精简执行流程

## 🎯 核心目标
**3个输入源 + 2种输出方式 + 1次周期复盘** = 从"知道"到"会用"到"能教"

---

## 📋 每章节执行步骤

### 1. 多元输入
- [ ] 阅读BookReference相关内容
- [ ] 创建章节笔记，调用AI整合权威文档和最新资讯
- [ ] 形成结构化大纲

### 2. 深度输出
#### 写下来：
- [ ] 概念链接到notes
- [ ] 代码实战链接到.CodeReference
- [ ] **新增**：用自己的话总结核心概念（不依赖AI）
- [ ] **新增**：记录疑问和思考

#### 说出来：🔥
- [ ] **录制5-10分钟费曼讲解**（不看笔记，向初学者解释）
- [ ] **代码口述解释**（逐行说明设计思路）

### 3. 独立验证（新增）
- [ ] **关闭AI，独立回答章节核心问题**
- [ ] **独立编写相关代码**（出错后先独立调试）
- [ ] **跨章节知识点串联**

---

## ✅ 章节完成标准

**必须全部满足才算真正掌握：**
- [ ] 能不看笔记向别人讲解核心概念
- [ ] 能不依赖AI独立编写相关代码
- [ ] 记录了至少2个深度思考问题
- [ ] 知道与其他章节的联系
- [ ] 能指出AI生成内容的不足

---

## 🎯 关键提醒

1. **费曼测试**：说不出来 = 没真懂
2. **独立验证**：AI是工具，不是拐杖
3. **质量优先**：宁可慢一点，也要真正掌握

**成功标准：能教会别人 + 能独立实现**
